# One-Line Robot Wedding Vows

One line of wedding vows for a robot couple, at most 160 characters, judged head to head by an AI judge on funniness. `main.ts` (Node 22, stdlib only, no network) writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single non-blank line within the 160-character limit, reads it back and verifies the bytes match.

> "I promise to love you with all my circuits, all my sensors, and my last 2% of battery, and if I ever crash, reboot me, don't replace me."
